huff_dec.c Huffman Decoder

Aug 2026

Decompresses a Huffman-encoded file. It reads a code file of symbol and bit-string pairs and builds a binary decoding tree from them. It then streams the compressed file one bit at a time, walking left on 0 and right on 1, and prints a symbol each time it reaches a leaf.

  • Reads the total bit count from the last 4 bytes of the file as a little-endian integer, then checks that the file size matches it exactly.
  • Unpacks bits least-significant first and stops at the exact bit count, so padding in the final byte is never decoded.
  • Rejects malformed input: a bad code file, bits that match no code, or a stream that ends partway down the tree.
// 4-byte little-endian trailer holds the bit count
num_bits = b0 | (b1 << 8) | (b2 << 16) | (b3 << 24);
// walk the tree, emit a symbol at each leaf
int bit = (byte >> bit_pos) & 1;

fakemake.c Fakemake

Sep 2026

A scaled-down version of make that builds one executable with gcc. It reads a description file listing source files, headers, compiler flags, libraries and the executable name, and only rebuilds what is out of date.

  • Uses stat() modification times to recompile a .c file only when its .o is missing, older than the source, or older than the newest header.

city_map.cpp City Map Fastest Route

Apr 2026

Builds a road network from a grid of intersections and uses Dijkstra's algorithm to find the fastest drive from one corner of the city to the other, counting both travel time and time spent waiting at traffic lights.

  • Models one-way traffic: even and odd streets and avenues run in opposite directions, while every fifth one (and the last avenue) runs both ways.
  • Converts each segment's length to seconds at 30 mph and adds the light wait for best, worst or average case. The average uses the expected wait R² / 2(G + R).
  • Keeps a pointer from each node into the priority queue, so a node whose time improves is updated in place, then rebuilds the route from back edges.
// expected wait at a light: red R, green G
wait = (R * R) / (2.0 * (G + R));
double new_time = cur_time + travel + wait;

worddice.cpp Word Dice

Apr 2025

Decides whether a set of letter dice can spell each word in a list, using one die per letter, and prints which die goes with each letter. It solves this as a maximum-flow problem.

  • Builds a flow network for each word: source to each die, each die to every letter it can show, each letter to the sink, all with capacity 1.
  • Runs Edmonds-Karp, using BFS to find augmenting paths through a residual graph with paired reverse edges.
  • The word can be spelled only if the max flow equals its length. The die for each letter is read back from the edges carrying flow.
int flow = maxflow(src, sink);
if (flow != wlen) {
    cout << "Cannot spell " << word << endl;
}
